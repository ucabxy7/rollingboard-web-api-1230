# Bootstrap API

This is a bootstrap repository for a Fastify/Prisma based API.

## Structure

### Tech stack

- API via Express
- Validation & serialisation via Zod
- ORM via Prisma
- DB via Postgres 17

### Infrastructure

- Dockerised
- API staging/production Docker images hosted on ECR
- API hosted on Elastic Beanstalk
- DB hosted on RDS

### How to start:

`make start`
